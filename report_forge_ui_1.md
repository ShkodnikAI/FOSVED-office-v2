## Расхождения с API (зафиксировано, бэкенд не тронут — прямое требование наряда)

`/api/dashboard` НЕ содержит `dialogs_today`/`spend_today`/`open_narads`/`alerts`/`recent_reports` (эти поля ждал прежний JS — до этого на главной всегда были «—»). Реальный ответ: `{status, kpis:{tasks, tasks_week, cost_today, cost_month, rating, reports}, depts, admin:{issues, proposals, ...}}`. Маппинг принят:
- **диалогов** = `kpis.tasks_week` (dialog_history за 7 дней; tasks = вызовы моделей за сегодня — не диалоги);
- **расход** = `kpis.cost_today` ($N.NN);
- **открыто нарядов** = `/api/narads` (статусы queued/approved/in_work/testing); fallback `admin.issues`;
- **Требует внимания** = `admin.issues` (замечания админа) + `admin.proposals`;
- **Последние отчёты** = `/api/archive` top-5 («dept · title», created).
