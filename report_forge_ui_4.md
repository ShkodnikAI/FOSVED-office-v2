## Блоки A–E

- **A.1 сделано (реально).** «Остаток дня» — из существующего `/api/budget/status` (`global.spent`/`global.limit`): при заданном лимите — «$X из $Y», при незаданном — честный «$N / лимит не задан» (не выдуман нулевой лимит). Сетка не захардкожена (гвард).
- **A.2 сделано (реально).** Провайдеры — 5 строк с точкой и статусом; **три состояния из реальных данных**: `on` (зелёный) — ключ есть и кулдаунов нет; `limit` (жёлтый, статус подсвечен `var(--yellow)`) — активный квотный кулдаун из `/health → quota_cooldowns` (причина + «вернётся через N мин» из `remaining_s`) или `provider_cooldowns` (long-cooldown); `off` (серый) — `status:"no_key"` из `/api/models`. Ссылка «Все 13 провайдеров и свои ключи» → экран Интеграций (существующий `data-go="integrations"`).
- **Блок B Голос — приглушён, интерактива нет (сознательное решение).** Тумблер голоса и выбор женского/мужского **должны** были вызывать реальные `/voice on|off`/`/voice male|female`. Проверка показала: команды живут **только в Telegram-контуре** (mlog webhook → `kv_set("voice_enabled"/"tts_voice")`); HTTP-эндпоинта, меняющего это состояние, в прокси нет. Единственный кандидат `/voice-set` — audit-заглушка (пишет лог, ничего не меняет) — вызывать его значило бы притворяться. По принципу наряда («честное разделение на работает сейчас / нужен наряд», «не притворяться») все голосовые пункты показаны приглушёнными (`opacity:.45`) с пометкой «нужен наряд», обработчиков клика нет (гварды запрещают и вызов voice-заглушки).
- **C.1 сделано (реально).** Тема — сегмент Тёмная/Светлая; это **второе место управления тем же состоянием**: и сегмент, и топбарный тумблер идут через единый `setTheme()` (атрибут data-theme + общий localStorage-ключ `theme` + meta theme-color + `applyThemeSeg()`), изменение отсюда мгновенно видно в топбаре и наоборот (гвард: единая функция).
- **C.2 сделано (реально).** Ориентация — три варианта **на отдельной строке под подписью** (set-row в column-режиме, seg-3 на всю ширину — по уроку наряда ничего не обрезается на 390px). Реальная блокировка через `screen.orientation.lock('portrait'|'landscape')` в try/catch + `.catch()`: если API недоступен (большинство десктопов) — выбор сохраняется в localStorage, отсутствие блокировки не считается ошибкой; «Авто» — `unlock()`.
- **Блок D сделан (честно).** «Своих расписаний пока нет. Сейчас работают только встроенные — утренний бриф и LZ Daily.» Кнопка «+ Добавить отчёт» есть, по клику — тост «Эта функция в разработке — нужен отдельный наряд». Не притворяется работающей.
- **Блок E — приглушён (сознательное решение).** «Модели по отделам»: чтение текущих оверрайдов `config/override_{dept}.txt` из HTTP не существует, сохранение через `/model <dept> <provider> <model>` — команда Telegram-контура (mlog `write_file`), HTTP-пути нет. Строить новый backend-мост — за рамками наряда («не трогаем реальную логику команд»), фейковый выбор запрещён принципом честности. Пункты приглушены с пометкой «нужен наряд» (гвард).

## Smoke-test — 6 пунктов

1. **Тема синхронна** — да: одно состояние `setTheme()` для топбара и Настроек (гвард `test_theme_single_state_two_controls`); живой проход за владельцем.
2. **Тумблер голоса реально включает/выключает** — **нет, сознательно**: HTTP-эндпоинта команды /voice не существует (Telegram-контур); пункт приглушён «нужен наряд» вместо фейкового тумблера (см. Блок B). Это отклонение от буквы smoke-test'а в пользу прямого требования наряда «не притворяться».
3. **Провайдер с реальным лимитом 429 — жёлтая точка и причина** — да: `quota_cooldowns` из `/health` с причиной и remaining_s → «вернётся через N мин», статус жёлтым (гвард).
4. **Три варианта ориентации не обрезаются на 390px** — да: отдельная строка под подписью, seg-3 width:100% (гвард структуры).
5. **Изменение модели отдела реально пишется в override** — **нет, сознательно**: HTTP-вызова /model нет; пункт приглушён «нужен наряд» (см. Блок E).
6. **Приглушённые пункты не реагируют на клик** — да: у `.muted-item` нет data-атрибутов-обработчиков, dispatcher их не ловит (гварды перечисляют все muted-пункты дословно).

## Затруднения

- Главное: smoke-пункты 2 и 5 предполагали существование HTTP-эндпоинтов голоса и модельных оверрайдов — их нет (команды живут в mlog-вебхуке Telegram). Вместо фейковых тумблеров — честное приглушение «нужен наряд»; для реального управления нужен наряд на тонкий мост HTTP→команды (например, расширение HandleMiniAppAction или отдельный read/write-эндпоинт override-ов) — зафиксировано как кандидат в бэклог.
- `/api/models` даёт статус ключа и mock-«limited» только для grok (по числу вызовов) — реальное состояние лимитов берётся из `/health` (QuotaTracker + long-cooldown), а mock-поле игнорируется.
- Прежние декоративные тумблеры (уведомления/отчёты) удалены вместе с CSS — они меняли только визуал без какого-либо состояния; наряд требует честности поверх декораций.
