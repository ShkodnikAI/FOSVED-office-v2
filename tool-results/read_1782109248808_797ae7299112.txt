    40→## 1. CLI команды
    41→
    42→Бинарник `mlog` поддерживает следующие команды:
    43→
    44→| Команда | Описание |
    45→|---------|----------|
    46→| `mlog run <file.mlog>` | Выполнить программу (или `.mbc` байткод) |
    47→| `mlog repl` | Интерактивная сессия (REPL) с историей команд |
    48→| `mlog check <file.mlog>` | Семантический анализ без выполнения |
    49→| `mlog serve <file.mlog>` | Запустить HTTP-сервер из `mlogserver`/`server` блока |
    50→| `mlog compile <file.mlog>` | Скомпилировать `.mlog` в `.mbc` байткод |
    51→| `mlog eval <file.mlog>` | Запустить `eval`-блоки (тестирование learnable patterns) |
    52→| `mlog resume <file.mlog> --flow=<name> --from=<checkpoint>` | Возобновить flow с контрольной точки |
    53→| `mlog audit <file.mlog>` | Статический security-аудит без выполнения |
    54→
    55→### Переменные окружения
    56→
    57→| Переменная | Описание |
    58→|------------|----------|
    59→| `METALOGOS_LLM_MOCK` | `true` (по умолчанию) — моковые LLM-ответы; `false` — реальные вызовы |
    60→| `METALOGOS_FORCE_PIPE` | `1` — принудительно использовать piped-режим REPL (для тестов) |

    64→## 2. Типы данных
    65→
    66→| Тип | Описание | Пример литерала |
    67→|-----|----------|-----------------|
    68→| `String` | Строка (UTF-8, Unicode-aware) | `"Привет мир"` |
    69→| `Float` | Число с плавающей точкой (все числа) | `42.0`, `3.14`, `-1.0` |
    70→| `Bool` | Булево значение | `true`, `false` |
    71→| `List` | Список значений | `[1.0, 2.0, "three"]` |
    72→| `Struct` | Именованная структура с полями | `{ name: "Alice", age: 25.0 }` |
    73→| `Html` | непрозрачный тип для безопасного HTML (авто-escaping) | — |
    74→| `Query` | непрозрачный тип для SQL-запросов (инъекция невозможна) | — |
    75→| `Secret` | непрозрачный тип для секретов (не печатается, не сериализуется) | — |
    76→| `Encrypted` | непрозрачный тип для зашифрованных данных | — |
    77→| `Hash` | непрозрачный тип для хешей паролей | — |
    78→| `Session` | непрозрачный тип для сессий | — |
    79→| `Unit` | Пустое значение (аналог `null`/`void`) | — |
    80→| `Fluid` | Вероятностный тип (суперпозиция вариантов с confidence) | — |
    81→
    82→> **Примечание:** В Металогосе нет отдельного типа `Int` — все числа являются `Float`.
    83→> Целые числа записываются как `42.0`. Для преобразования строки в целое используйте `to_int()`.

    87→## 3. Синтаксис
    88→
    89→### 3.1. Комментарии
    90→
    91→```mlog
    92→// однострочный комментарий
    93→```
    94→
    95→### 3.2. Переменные и привязки
    96→
    97→```mlog
    98→let x = 42.0
    99→let name = "Metalogos"
   100→let items = [1.0, 2.0, 3.0]
   101→let result = if x > 10.0 then "big" else "small"   // let с if-выражением
   102→let payload = { chat_id: "123", text: "hello", urgent: true }  // struct literal
   103→```
   104→
   105→### 3.3. Операторы
   106→
   107→| Категория | Операторы |
   108→|-----------|-----------|
   109→| Арифметические | `+`, `-`, `*`, `/` |
   110→| Сравнение | `==`, `!=`, `>`, `<`, `>=`, `<=` |
   111→| Логические (short-circuit) | `and`, `or` |
   112→| Унарный минус | `-expr` |
   113→| Доступ к полю | `obj.field` |
   114→| Доступ по индексу | `list[0]` |
   115→| Вызов функции | `func(arg1, arg2)` |
   116→| Квалифицированный вызов | `module.func(arg)` |
   117→
   118→### 3.4. Управляющие конструкции
   119→
   120→**If-else (блочная форма):**
   121→```mlog
   122→if x > 10.0 {
   123→  print("big")
   124→} else if x > 5.0 {
   125→  print("medium")
   126→} else {
   127→  print("small")
   128→}
   129→```
   130→
   131→**If-then-else (тернарное выражение):**
   132→```mlog
   133→let label = if score >= 90.0 then "A" else "B"
   134→```
   135→
   136→**If-then (блочный оператор):**
   137→```mlog
   138→if x > 10.0 then {
   139→  print("big")
   140→} else if x > 5.0 then {
   141→  print("medium")
   142→} else {
   143→  print("small")
   144→}
   145→```
   146→
   147→**Each (цикл по коллекции):**
   148→```mlog
   149→each item in items {
   150→  print(item)
   151→}
   152→```
   153→
   154→**Each with index (цикл с индексом):**
   155→```mlog
   156→each i, item in items {
   157→  print(to_string(i) + ": " + item)
   158→}
   159→```
   160→
   161→**While (цикл с условием):**
   162→```mlog
   163→while count < 10.0 {
   164→  let count = count + 1.0
   165→}
   166→```
   167→
   168→**Break / Continue:**
   169→```mlog
   170→each item in items {
   171→  if item == "stop" then { break }
   172→  if item == "skip" then { continue }
   173→  print(item)
   174→}
   175→```
   176→
   177→**Match (сопоставление с образцом):**
   178→```mlog
   179→match command {
   180→  "start" then { print("starting") }
   181→  starts_with "stop" then { print("stopping") }
   182→  contains "help" then { print("helping") }
   183→  > 100.0 then { print("too big") }
   184→  else { print("unknown") }
   185→}
   186→```
   187→
   188→**Try (перехват ошибок):**
   189→```mlog
   190→let result = try risky_operation()
   191→// Если risky_operation() вернёт ошибку, result = Unit
   192→```
   193→
   194→**Return:**
   195→```mlog
   196→return result
   197→```
   198→
   199→### 3.5. Строковые литералы
   200→
   201→```mlog
   202→let s = "hello world"
   203→let with_escape = "line1\nline2\ttabbed"
   204→```
   205→
   206→Поддерживаемые escape-последовательности: `\"`, `\\`, `\n`, `\t`, `\r`, `\uXXXX` (Unicode code point, например `\u0041` = `A`).
   207→
   208→### 3.6. Идентификаторы
   209→
   210→Идентификаторы поддерживают ASCII, `_` и кириллицу (А-я):
   211→```mlog
   212→let имя = "Metalogos"
   213→let счетчик = 0.0
   214→pattern Приветствие(кто: String) -> String { ... }
   215→```

   219→## 4. Встроенные функции (Builtins)
   220→
   221→Все 93 встроенные функции регистрируются в `src/builtins.rs` и доступны как в tree-walking интерпретаторе, так и в байткод VM. JIT-компилятор через Cranelift также поддерживает все builtins.
   222→
   223→### 4.1. Строковые функции
   224→
   225→| Функция | Сигнатура | Возврат | Описание |
   226→|---------|-----------|---------|----------|
   227→| `upper(s)` | `String -> String` | String | Преобразует строку в верхний регистр |
   228→| `lower(s)` | `String -> String` | String | Преобразует строку в нижний регистр |
   229→| `trim(s)` | `String -> String` | String | Убирает пробелы по краям |
   230→| `replace(s, old, new)` | `String, String, String -> String` | String | Заменяет все вхождения `old` на `new`. Unicode-aware, работает с кириллицей и эмодзи |
   231→| `split(s, sep)` | `String, String -> List` | List | Разделяет строку по разделителю. Пустой разделитель разбивает посимвольно |
   232→| `join(items, sep)` | `List, String -> String` | String | Объединяет элементы списка через разделитель. По умолчанию `","` |
   233→| `index_of(s, needle)` | `String, String -> Float` | Float | Возвращает позицию (символьную, не байтовую) первого вхождения или `-1.0` |
   234→| `substring(s, start, end)` | `String, Float, Float -> String` | String | Извлекает подстроку по символьным индексам. Soft-failure: пустая строка при out-of-bounds |
   235→| `char_at(s, index)` | `String, Float -> String` | String | Возвращает символ по индексу. Пустая строка при out-of-bounds |
   236→| `starts_with(s, prefix)` | `String, String -> Bool` | Bool | Проверяет, начинается ли строка с префикса. Также доступна как VM-инструкция `StartsWith` и в `match` как `starts_with "..."` |
   237→| `ends_with(s, suffix)` | `String, String -> Bool` | Bool | Проверяет, заканчивается ли строка суффиксом |
   238→| `contains(s, needle)` | `String, String -> Float` | Float | Возвращает `1.0` если содержит, `0.0` если нет. Также доступна как VM-инструкция `Contains` |
   239→| `reverse(s)` | `String -> String` | String | Разворачивает строку (посимвольно) |
   240→| `length(s)` | `String -> Float` | Float | Длина строки в символах (Unicode-aware). Аналог `len()` |
   241→| `len(s)` | `String\|List -> Float` | Float | Длина строки (символы) или списка (элементы) |
   242→| `escape_html(s)` | `String -> String` | String | Экранирует HTML-спецсимволы: `& < > " '` |
   243→| `escape_json(s)` | `String -> String` | String | Экранирует JSON-спецсимволы: `" \ \n \t \r` |
   244→
   245→**Примеры:**
   246→```mlog
   247→let s = "Привет, мир!"
   248→upper(s)              // "ПРИВЕТ, МИР!"
   249→lower(s)              // "привет, мир!"
   250→trim("  hello  ")     // "hello"
   251→replace(s, "мир", "свет")  // "Привет, свет!"
   252→split("a,b,c", ",")   // ["a", "b", "c"]
   253→join([1.0, 2.0], "-") // "1-2"
   254→index_of(s, "мир")    // 8.0
   255→substring(s, 0.0, 6.0) // "Привет"
   256→char_at(s, 8.0)       // "м"
   257→starts_with(s, "Прив") // true
   258→ends_with(s, "!")      // true
   259→contains(s, "ет")      // 1.0
   260→reverse("abc")         // "cba"
   261→length("Привет")       // 6.0
   262→len([1.0, 2.0, 3.0])  // 3.0
   263→escape_html("<script>alert('xss')</script>")
   264→  // "&lt;script&gt;alert(&#39;xss&#39;)&lt;/script&gt;"
   265→escape_json("hello\"world\n")  // "hello\\\"world\\n"
   266→```
   267→
   268→### 4.2. Числа и математика
   269→
   270→| Функция | Сигнатура | Возврат | Описание |
   271→|---------|-----------|---------|----------|
   272→| `abs(n)` | `Float -> Float` | Float | Абсолютное значение |
   273→| `min(a, b)` | `Float, Float -> Float` | Float | Минимум из двух чисел |
   274→| `max(a, b)` | `Float, Float -> Float` | Float | Максимум из двух чисел |
   275→| `clamp(val, lo, hi)` | `Float, Float, Float -> Float` | Float | Ограничивает значение диапазоном `[lo, hi]` |
   276→| `round(n)` | `Float -> Float` | Float | Округление до ближайшего целого |
   277→| `to_float(s)` | `String\|Float\|Bool -> Float` | Float | Преобразует в Float. Soft-failure: `0.0` |
   278→| `to_int(s)` | `String\|Float\|Bool -> Float` | Float | Преобразует в целое (усекает дробную часть). Soft-failure: `0.0` |
   279→| `float(s)` | `String\|Float -> Float` | Float | Аналог `to_float()`, но с ошибкой при невалидной строке |
   280→
   281→**Примеры:**
   282→```mlog
   283→abs(-5.5)          // 5.5
   284→min(3.0, 7.0)      // 3.0
   285→max(3.0, 7.0)      // 7.0
   286→clamp(15.0, 0.0, 10.0)  // 10.0
   287→round(3.7)         // 4.0
   288→to_float("3.14")   // 3.14
   289→to_int("42abc")    // 0.0 (soft-failure)
   290→to_int(3.9)        // 3.0
   291→```

   293→### 4.3. Коллекции (List)
   294→
   295→| Функция | Сигнатура | Возврат | Описание |
   296→|---------|-----------|---------|----------|
   297→| `get(list, index)` | `List, Float -> Value` | Value | Получить элемент по индексу. Ошибка при out-of-bounds |
   298→| `push(list, item)` | `List, Value -> List` | List | Добавить элемент в конец (возвращает новый список) |
   299→| `first(list)` | `List -> Value` | Value | Первый элемент. Пустая строка если список пуст |
   300→| `last(list)` | `List -> Value` | Value | Последний элемент. Пустая строка если список пуст |
   301→| `len(list)` | `List -> Float` | Float | Количество элементов |
   302→| `length(list)` | `List -> Float` | Float | Аналог `len()` |
   303→| `reverse(list)` | `List -> List` | List | Разворачивает список |
   304→| `make_list(a, b, c, ...)` | `Any, ... -> List` | List | Создаёт список из произвольного числа аргументов. Потокобезопасная альтернатива write_file/read_file для возврата нескольких значений из pattern (Наряд 24) |
   305→
   306→**Примеры:**
   307→```mlog
   308→let items = [10.0, 20.0, 30.0]
   309→get(items, 1.0)        // 20.0
   310→push(items, 40.0)      // [10.0, 20.0, 30.0, 40.0]
   311→first(items)           // 10.0
   312→last(items)            // 30.0
   313→len(items)             // 3.0
   314→reverse(items)         // [30.0, 20.0, 10.0]
   315→```

   327→### 4.5. LLM и AI
   328→
   329→| Функция | Сигнатура | Возврат | Описание |
   330→|---------|-----------|---------|----------|
   331→| `call_llm(prompt, input)` | `String, String -> String` | String | Вызывает LLM-бэкенд. По умолчанию возвращает мок: `"[MOCK: prompt \| input]"`. Реальный вызов при `METALOGOS_LLM_MOCK=false`. Таймаут 120с |
   332→| `call_claude(api_key, model, system_prompt, user_message)` | `String, String, String, String -> String` | String | Прямой вызов Anthropic Claude Messages API (v1/messages). Возвращает `content[0].text`. Таймаут 120с |
   333→| `llm_usage()` | `-> Struct` | Struct `{LlmUsage}` | Статистика использования LLM: `total_calls`, `total_tokens`, `total_errors`, `providers` (список `{alias, calls, tokens, errors, avg_latency_ms, health_score}`) |
   334→| `confidence(fluid_value)` | `Fluid -> Float` | Float | Возвращает максимальный confidence вероятностного типа. Для конкретных значений возвращает `1.0` |
   335→
   336→**Пример:**
   337→```mlog
   338→let result = call_llm("Translate to English", "Привет мир")
   339→// По умолчанию: "[MOCK: Translate to English | Привет мир]"
   340→
   341→let claude_response = call_claude(env("ANTHROPIC_KEY"), "claude-sonnet-4-20250514", "You are helpful.", "Hello!")
   342→```

   344→### 4.6. HTTP
   345→
   346→| Функция | Сигнатура | Возврат | Описание |
   347→|---------|-----------|---------|----------|
   348→| `http_post(url, body)` | `String, String -> String` | String | POST-запрос. Content-Type по умолчанию `application/json`. Таймаут 30с. Ошибка при статусе >= 400 |
   349→| `http_post(url, body, content_type)` | `String, String, String -> String` | String | POST с указанным Content-Type |
   350→| `http_post(url, body, content_type, headers)` | `String, String, String, String\|Struct -> String` | String | POST с заголовками. Если 4-й аргумент String — устанавливается `Authorization: Bearer <token>`. Если Struct — устанавливаются заголовки из полей |
   351→| `http_get(url)` | `String -> String` | String | GET-запрос. Таймаут 30с. Ошибка при статусе >= 400 |
   352→| `http_get(url, headers)` | `String, String\|Struct -> String` | String | GET с заголовками (Bearer token или Struct) |
   353→| `http_post_multipart(url, fields, files)` | `String, String\|Struct, String\|List -> String` | String | Multipart POST. `fields` — JSON-строка или Struct с текстовыми полями. `files` — JSON-массив `[{name, path, mime}]` или List of Structs |
   354→| `http_post_multipart(url, fields, files, headers)` | `String, String\|Struct, String\|List, String\|Struct -> String` | String | Multipart POST с заголовками |
   355→
   356→**Примеры:**
   357→```mlog
   358→// Простой POST
   359→let resp = http_post("https://api.example.com/data", json_encode(payload))
   360→
   361→// POST с Bearer-токеном
   362→let resp = http_post("https://api.example.com/data", body, "application/json", env("API_TOKEN"))
   363→
   364→// POST с кастомными заголовками
   365→let headers = { "X-Custom": "value", "Authorization": "Bearer token123" }
   366→let resp = http_post("https://api.example.com/data", body, "application/json", headers)

   389→### 4.7. JSON
   390→
   391→| Функция | Сигнатура | Возврат | Описание |
   392→|---------|-----------|---------|----------|
   393→| `parse_json(text)` | `String -> Struct\|List\|String\|Float\|Bool\|Unit` | Any | Парсит JSON-строку. Объекты → Struct с `type_name: "Json"`, массивы → List, `null` → Unit |
   394→| `json_encode(value)` | `Any -> String` | String | Сериализует значение в JSON-строку. Поддерживает String, Float, Bool, Unit→null, List→array, Struct→object |
   395→| `json_get(obj, field_path)` | `Struct, String -> Value` | Value | Безопасный доступ к полю (возвращает Unit если нет поля). Unit корректно сравнивается через `==`/`!=` с любым типом. Поддерживает dot-path: `"voice.file_id"`. **Поддерживает числовые индексы массивов:** `"items.0.title"` (Наряд 24) |
   396→| `json_get(obj, field_path, default)` | `Struct, String, Value -> Value` | Value | С дефолтным значением при отсутствии поля. Также поддерживает числовые индексы |
   397→| `has_field(obj, field_path)` | `Struct, String -> Float` | Float | `1.0` если поле существует, `0.0` если нет. Поддерживает dot-path |
   398→| `escape_json(text)` | `String -> String` | String | Экранирует спецсимволы для встраивания в JSON |
   399→
   400→**Примеры:**
   401→```mlog
   402→let data = parse_json("{\"name\": \"Alice\", \"age\": 30}")
   403→let name = json_get(data, "name")           // "Alice"
   404→let missing = json_get(data, "email")        // Unit
   405→let missing = json_get(data, "email", "none") // "none"
   406→
   407→let nested = parse_json("{\"a\": {\"b\": 42}}")
   408→json_get(nested, "a.b")                      // 42.0
   409→has_field(nested, "a.b")                     // 1.0
   410→
   411→let encoded = json_encode({ key: "value", n: 42.0 })
   412→// "{\"key\":\"value\",\"n\":42.0}"
   413→```

   415→### 4.8. Файловый I/O
   416→
   417→> **Важно:** Все файловые операции песочницей ограничены рабочей директорией.
   418→> Абсолютные пути и `..` (path traversal) отклоняются.
   419→
   420→| Функция | Сигнатура | Возврат | Описание |
   421→|---------|-----------|---------|----------|
   422→| `read_file(path)` | `String -> String` | String | Читает файл. Soft-failure: пустая строка при ошибке |
   423→| `write_file(path, content)` | `String, String -> String` | String | Пишет файл (перезапись). Возвращает `"ok"` или `""` при ошибке |
   424→| `append_file(path, content)` | `String, String -> String` | String | Добавляет в конец файла. Возвращает `"ok"` или `""` |
   425→| `delete_file(path)` | `String -> String` | String | Удаляет файл. Возвращает `"ok"` или `""` |
   426→| `file_exists(path)` | `String -> Bool` | Bool | Проверяет существование файла |
   427→| `list_dir(path)` | `String -> List` | List | Список файлов в директории. Без аргумента — текущая директория |
   428→
   429→**Примеры:**
   430→```mlog
   431→write_file("data.txt", "hello world")  // "ok"
   432→let content = read_file("data.txt")   // "hello world"
   433→append_file("data.txt", "\nmore")     // "ok"
   434→file_exists("data.txt")               // true
   435→let files = list_dir(".")             // ["data.txt", ...]
   436→delete_file("data.txt")               // "ok"
   437→```

   464→### 4.11. Шифрование и безопасность
   465→
   466→| Функция | Сигнатура | Возврат | Описание |
   467→|---------|-----------|---------|----------|
   468→| `env(key)` | `String -> String` (→ `Secret` в entity context) | String/Secret | Читает переменную окружения. Пустая строка если не найдена |
   469→| `generate_key()` | `-> Secret` | Secret | Генерирует 256-битный случайный ключ (64 hex-символа) |
   470→| `encrypt(data, key)` | `String, Secret -> Encrypted` | Encrypted | Шифрует AES-256-GCM со случайным 96-бит nonce. Ключ — 64 hex-символа |
   471→| `decrypt(encrypted, key)` | `Encrypted, Secret -> String` | String | Расшифровывает AES-256-GCM. Ошибка при неверном ключе |

   477→**Примеры:**
   478→```mlog
   479→entity db_url: Secret = env("DATABASE_URL")
   480→let key = generate_key()
   481→let encrypted = encrypt("secret data", key)
   482→let decrypted = decrypt(encrypted, key)  // "secret data"
   483→
   484→let hash = hash_password("mypassword")     // Hash (opaque)
   485→verify_password("mypassword", hash)        // true
   486→verify_password("wrong", hash)             // false
   487→
   488→require(user.role == "admin")              // паника если не admin
   489→require(age >= 18.0, "Access denied")      // с сообщением
   490→```

   605→## 4.18. Scoping: область видимости `let`
   606→
   607→**Важно:** `let` внутри `if`, `while`, `each` блоков создаёт **новую лексическую переменную**, видимую только внутри этого блока. Она **не затрагивает** внешнюю переменную с тем же именем.
   608→
   609→```mlog
   610→let handled = 0.0
   611→if user_id != owner_id {
   612→  let handled = 1.0   // ← это НОВАЯ переменная, видна только здесь
   613→}
   614→// Внешний handled всё ещё 0.0!
   615→```
   616→
   617→**Как изменить внешнюю переменную:** используйте прямое присваивание (без `let`):
   618→```mlog
   619→let handled = 0.0
   620→if user_id != owner_id {
   621→  handled = 1.0   // ← присваивание в существующую переменную
   622→}
   623→// Теперь handled == 1.0
   624→```

   629→
   630→Metalogos имеет три бэкенда выполнения:

   739→```mlog
   740→server {
   741→  port: 8080
   742→  middleware: [session, csrf, security_headers]
   743→
   744→  route "/" method=GET {
   745→    respond("200 OK")
   746→  }
   747→
   748→  route "/admin" method=GET requires=[admin] {
   749→    respond("200 Secret")

   754→Ключевое слово `server` — синоним `mlogserver`.

   756→Доступные middleware: `session`, `csrf`, `security_headers`.

   861→### 6.15. Sandbox, Mutate, Adapt, Memorize, Forget, Relate
   862→
   863→```mlog
   864→// Sandbox (ограничение выполнения)
   865→sandbox safe_executor {
   866→  allowed: [upper, lower, trim, split],
   867→  forbidden: [http_post, http_get, write_file],
   868→  timeout: 5
   869→}
   870→
   871→// Mutate (адаптация с откатом)
   872→mutate Classify {
   873→  add_example("new input", "new output")
   874→  rollback_if: accuracy < 0.7
   875→}
   876→
   877→// Adapt (добавление примера)
   878→adapt Classify add_example("input", "output")
   879→
   880→// Memorize / Forget (семантическая память)
   881→memorize "important fact" with priority = 0.9
   882→forget "outdated fact" after 30.0 days
   883→
   884→// Relate (знаковый граф)
   885→relate entity1 to entity2 as "relationship"
   886→```

   906→## 7. Stdlib (стандартная библиотека)
   907→
   908→Стандартная библиотека находится в `std/` и подключается через `import`:
   909→
   910→### std/string
   911→
   912→```mlog
   913→import std/string as str
   914→
   915→str.trim(s: String) -> String       // trim whitespace
   916→str.replace(s, old, new) -> String  // replace all occurrences
   917→str.split(s, sep) -> List           // split by separator
   918→str.join(items, sep) -> String      // join list into string
   919→```
   920→
   921→### std/math
   922→
   923→```mlog
   924→import std/math
   925→
   926→math.abs(n: Float) -> Float         // absolute value
   927→math.min(a, b) -> Float             // minimum
   928→math.max(a, b) -> Float             // maximum
   929→math.clamp(val, lo, hi) -> Float    // clamp to range
   930→math.round(n) -> Float              // round to nearest
   931→```
   932→
   933→### std/collections
   934→
   935→```mlog
   936→import std/collections
   937→
   938→collections.first(items: List) -> String   // first element
   939→collections.last(items: List) -> String    // last element
   940→collections.push(items, item) -> List      // append to list
   941→```
   942→
   943→> **Примечание:** Все функции stdlib также доступны как top-level builtins (без импорта):
   944→> `trim()`, `replace()`, `split()`, `join()`, `abs()`, `min()`, `max()`, `clamp()`, `round()`, `first()`, `last()`.
