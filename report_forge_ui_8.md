## Блок A — список

- **Сделано.** Список из реального `INTEGRATIONS_REGISTRY` через существующий `/api/integrations` (логика реестра и set/delete/get_secret не тронуты). Группы **«Модели (N)» / «Сервисы (N)»** — счётчики считаются из фактического количества записей реестра в JS (`nM/nS`), не захардкожены (гвард запрещает литеральные «Модели (13)»). Точка: `.int-dot.on` зелёная — ключ задан, серая — не задан (`x.connected` из API). Строка кликабельна целиком (`data-int-key/label/source`). **Статус-текст «подключён»/«не задан» — вместо прежней маски**: наряд запрещает показывать значение даже частично, поэтому `masked` больше не попадает в интерфейс вообще (гвард: `x.masked`/`r.masked` отсутствуют в индексе; подзаголовок экрана усилен: «— даже частично»).
- **Поиск** — строка с лупой сверху, фильтрует по названию/id **в реальном времени** (`input` → `renderIntegrations()` без запросов и перезагрузок).

## Блок B — лист ввода ключа

- **Сделано.** Подключённый провайдер: поле с плейсхолдером-маской «••••••••», кнопка **«Убрать значение» активна** (attribute `hidden` снят). Неподключённый: пустое поле с плейсхолдером «Вставь ключ», кнопка «Убрать» **не рендерится** — `hidden=!connected`, т.е. не показывается даже неактивной (гвард: ровно один элемент в разметке, состояние тогглится). Подзаголовок листа объясняет источник: «Задано через это приложение» / «Задано в окружении сервера» / «Пока не подключено».
- **Сохранение** — реальный POST `/api/integrations/<key>` (существующий `set_secret`), **удаление** — реальный DELETE (существующий `delete_secret`); handlers и audit-логи эндпоинтов не менялись.
- **Обновление без перезагрузки**: после сохранения/удаления — `refreshIntegrations()` перечитывает список и перерисовывает статус строки; `location.reload` в коде отсутствует (гвард).

## Затруднения

- Прежний рендер показывал `masked` (частичную маску значения) прямо в списке — это противоречило уточнению наряда «не показывать даже частично»; маска убрана из UI полностью (API по-прежнему отдаёт `masked` — поле оставлено в контракте для совместимости, фронтом не используется).
- Кнопка «Убрать значение» для env-источника: `delete_secret` снимает DB-оверрайд; если ключ задан переменной окружения, он останется «подключённым» после удаления оверрайда — это семантика существующего `get_secret` (env → db приоритеты), не менялась. Подзаголовок листа честно показывает источник.
- Live-клик-проход — за владельцем после деплоя (миниапп за initData-гейтом SEC-4).
