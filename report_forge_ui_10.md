## Блок A — Сайты (RSS): реально работает

- **Состояние лент** — новая ленивая таблица `rss_sources` (feed/url/name/tag/enabled/custom/deleted). При первом доступе в неё сеедятся **все 15 реальных лент из `RSS_FEEDS`** (INSERT OR IGNORE — добавление новых в коде продолжит работать); поведенческий тест: количество == len(RSS_FEEDS).
- **Тумблер — реальный**: POST `/api/lz/rss/<feed>/toggle` пишет `enabled`; **`collect_rss()` ходит по `rss_enabled_feeds()`** (новый хелпер: enabled=1 AND deleted=0) — выключенная лента реально пропускается при следующем сборе (тест: ria выключена → в активных нет, tass на месте; spy-тест подтверждает, что collect_rss использует хелпер).
- **Крестик — реальное удаление**: для кодовых лент — мягко (`deleted=1, enabled=0` — иначе лента вернулась бы при сеединге из кода); для добавленных владельцем — строка удаляется физически.
- **Добавление сайта по ссылке** — POST `/api/lz/rss` с **валидацией feedparser'ом ДО сохранения** (`rss_validate_url`: bozo без entries → отказ; нет title и entries → отказ); тесты: рабочая лента сохраняется (title извлекается), заведомо нерабочая — 400 и записи нет.

## Затруднения

- Статусы TG/YT/TikTok в наряде устарели (MON уже реализованы) — статусы показывают актуальную реальность вместо устаревшей заглушки; сами кнопки всё равно неактивны: HTTP-эндпоинтов управления каналами нет (Telegram-команды) — тот же принцип честности, что в UI-4/UI-2.
