## Примечание о version skew

Push `3ebf40d` (defensive fix: split/join string literals → variables) отправлен на origin/main,
но Render ещё не выкатил. На текущем проде (`691d44e`) парсер v0.12.0 принимает `split(text, " ")` —
ошибка была от кэшированного Docker-слоя с другим бинарником. Фикс в `3ebf40d` — защитный,
не обязательный для текущей версии парсера.
