# Отчёт: FORGE-UI-11 — альбомная ориентация (Главная, Наряды, Чат)

Дата: 2026-09-19. Ветка: fo-forge-ui/landscape → PR → squash в main → деплой Render (авто).
Тесты: 590 → 597 (+7 гвардов UI-11). **Волна FORGE-UI-0…11 полностью закрыта.**

## Блок A — боковая навигация

- **Сделано, чистый CSS.** Media-запрос `@media (orientation: landscape) and (min-width: 700px)` (учитывает планшеты). Внутри: нижний `.dock` переезжает в левую боковую панель — `position:fixed; left:0; top:0; bottom:0; width:76px`, вертикальная раскладка, `border-right:1px solid var(--line)`, фон `var(--surface)`, `#app` получает `padding-left:76px`. Пункты и иконография — **те же пять** (DOM не менялся, меняется только раскладка дока); кнопки держат минимальную высоту и вертикальный ритм (gap 6px, padding 16px 0 — значения из наряда).

## Блок B — Главная: двухколоночная раскладка

- **Сделано.** `.screen[data-tab="home"] .scroll` → `display:grid; grid-template-columns:1.1fr 1fr; gap:0 18px`. Левая колонка: герой-баннер (row 1) + три карточки статистики (row 2). Правая колонка: «Требует внимания» (row 1) + алерты (row 2) + «Последние отчёты» (rows 3–4). Явное размещение по grid-column/row — без прокрутки видны обе колонки верхней части; числа статистики в трёх карточках не обрезаются (карточки остались в левой колонке той же ширины, что и в портрете).

## Блок C — Наряды и Чат

- **Наряды**: одна колонка (карточки достаточно широкие), контент ограничен `max-width:760px; margin:0 auto` — фильтры с горизонтальной прокруткой не обрезаются, деталь наряда читаема на альбомной ширине.
- **Чат**: выбран вариант «широкая единая колонка с ограничением» — контент 760px по центру, **пузыри ограничены `max-width:520px`**, чтобы не растягивались на всю альбомную ширину; овальные кнопки отделов остались вверху с горизонтальной прокруткой (на альбомной ширине помещаются целиком).

## Остальные экраны — что сделано

- **Общий принцип применён ко всем**: боковая навигация (единый `#app{padding-left:76px}` + переезд дока) и центрирование контента `max-width:760px` действуют для Архива, Ещё, Настроек, Проектов, Интеграций, Закупок, Источников ЛЗ, Телеметрии (гвард перечисляет все табы). Специализированные двухколоночные раскладки — только Главная (обязательный минимум выполнен; остальные экраны по возможности — центрирование как минимальная адаптация).
