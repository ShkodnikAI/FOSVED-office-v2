## Режим доступа (директива владельца 2026-09-15, §16.0-7 плана)

- Правка плана — ТОЛЬКО здесь, правкой первой (§16.0-1); публичный репо канона не получает.
- Публично допускается только автогенерируемая выжимка `docs/PLAN-SUMMARY.md` в Metalogos
  (перечень фаз, текущая волна, критерии — без рыночного анализа §3/§15, обоснований
  секвенции §4–§6, ставок §14, риск-реестра §18, полного реестра волн §16).
- В issues публичного репо не пересказываются: рыночный анализ, обоснования приоритетов,
  опережающие ставки. Санитизация: тело наряда = задача, якоря, приёмка.
