# FOIP — Протокол излучения фишками

> Обязательный протокол для любого предложения улучшения офиса.
> Офис только улучшается. Накопленные способности не теряются.

---

## Как это работает

**Шаг 1. Карточка фичи** (показываю владельцу)

```
ФИЧА: <название>
ДЕЛАЕТ: <что делает, 1-2 предложения>
УЛУЧШАЕТ: <что конкретно улучшает в офисе>
НАТИВНОСТЬ: <X>% — нативный Металогос
```

Если Металогосу не хватает функции:
```
НАРЯД НА МЕТАЛОГОС: <какая функция нужна, зачем>
```

Вердикт: **Рекомендую к реализации** / **Отложить** / **Отклонить**

Владелец решает: реализуем или нет.

---

**Шаг 2. План реализации** (только после одобрения)

- Наряды с конкретными файлами и зависимостями
- Порядок: сначала новый функционал, потом удаление мусора
- Тесты после каждого наряда
- Откат при провале

---

## Правила

1. **Мусор удаляется только после полной реализации замены.** Не раньше.
2. **Яна не деградирует.** Любое изменение Яны — тест до/после, при ухудшении откат.
3. **Нативный Металогос приоритет.** Если языка не хватает — пишем наряд на обогащение языка, а не костыли.
4. **Не ломаем работающее.** Перед удалением кода — проверка что он не вызывается (rg).
