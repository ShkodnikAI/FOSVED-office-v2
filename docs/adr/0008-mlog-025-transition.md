# ADR-0008: Переход боевого бинаря Metalogos с 0.24.0 на 0.25.0

**Статус:** принято (office#372 — office-параллель Волны 15, 2026-09-25;
прецедент: office#349→ADR-0005, office#353→ADR-0006, N024→ADR-0007)
**Дата:** 2026-09-25
**Контекст решения:** Metalogos v0.25.0 = Wave 15 (squash afbcfc7, release
наряд №451, статический контур Фазы 1): полный statement-kind вывод
TAINT_INTERP — Match-arms с lattice-join слияниями состояний,
break/continue-границы потока, memory-варианты (memorize/forget/relate)
как persist-факты; модуль эффектов билтинов (taint-событие несёт effects:
read/write/network — derived из классификации №316, call_llm prompt-эгресс
— DUAL-контракт); честный пересчёт REALITY 6.10 (P0-readiness 82→85%,
Labels 75→87). Вся волна — статический слой: **заявлен ноль изменений
рантайма**; статический словарь check_id не менялся (35); leak-корпус
40→44 негативов / 22→26 позитивов (0 ложных срабатываний на новых kinds);
overhead +6% (depth 4) — в лимитах.

**Сборка:** бинарь 0.25.0 взят **из официального CI upstream** (путь
ADR-0007): workflow «Build and Release» на коммите тега `v0.25.0`
(afbcfc7, run 36073560354, job build success), артефакт
`mlog-linux-x86_64` (32 318 568 байт после распаковки, ELF x86-64).
`mlog --version` → `mlog mlog 0.25.0` (grammar rev: 1).

## Решение

**`bin/mlog` = 0.25.0.** Guard-цепочка entrypoint сохранена без изменения
механики: кандидат = `bin/mlog`, проба audit на аугментированной копии
(мост №421), бут-фолбэк = `bin/mlog-020` (0.20.0). **`bin/mlog-024`
вендорен как прошлый-хороший/тест-гвард** (роль mlog-023 из ADR-0007
переходит к нему); **`bin/mlog-023` выведен из репо** (восстанавливается
из git-истории, прецедент mlog-022 из ADR-0007). bin/ несёт 0.25 + 0.24 +
0.20 (~88 МБ, вес ротации не изменился).

Сопутствующее (попутно найдено, починено в рамках ротации): CI-гвард
№312 (`.github/workflows/ci.yml`) продолжал ссылаться на выведенный из
репо `bin/mlog-022` — шаг падал бы `chmod: not found` (CI на свежих
коммитах не прогонялся до конца — queued/cancelled, поломка не была
поймана). Гвард переведён на `bin/mlog-024` (совместимость обоснована
B.2.4: аудит dept на 0.25 ≡ 0.24 байт-идентично). Аналогично обновлён
pytest-гвард `test_binary_prev_good_vendored`
(tests/test_schedules_native.py).

## Что проверено (методология ADR-0005/0006/0007, блоки B.2–B.4)

1. **Статика `check app.mlog`:** rc=1 (известный базлайн, 0 parse error)
   — вывод **байт-идентичен** 0.24↔0.25.
2. **Статика `audit`:** raw (rc=1, те же 42 строки [ERROR] долга №327,
   0 Category A) и с мостом №421 (`profile legacy {
   egress: permissive_with_audit }`, rc=2, 0 [ERROR]) — **байт-идентичны**
   0.24↔0.25. Гвард-проба entrypoint на кандидате пройдёт (aug rc=2).
3. **Гвард dept-модулей:** все 27 `dept/*.mlog` — check на 0.25, rc и
   выводы байт-идентичны 0.24 (0 строк [ERROR]).
4. **Байткод:** `compile` rc=0 на обоих; размер .mbc совпадает
   (1 840 965 байт — совпадает с эталоном ADR-0007). **Перекрёстное
   исполнение .mbc**: app-байткод (024/025) × (0.24/0.25) — 4/4 rc=0;
   пробник `probe.mlog` (each/структуры/get/trim/len/str-конкатенация) —
   compile 0 ошибок на обоих, кросс-исполнение 4/4 rc=0, выводы
   байт-идентичны — claim CHANGELOG «no runtime behavior change»
   подтверждён на офисной поверхности. Методологическое примечание
   ADR-0007 в силе: байт-в-байт сравнение .mbc между версиями невозможно
   и не требуется (constant-pool рандомизирован per-process).
5. **Serve-батарея (B.3):** полный стек на интерпретаторе (мост, env-
   allowlist ценза, боевой sqlite), 34 декларированных роута app.mlog +
   прокси-поверхность (/miniapp-spa, /dept-dashboard, /metrics/activity,
   /api/session, /shop/dossier/, /lz/diagnose) + POST /webhook/telegram
   — **40 проб, 40 KEEP, 0 DIFF** (коды и размеры тел попарно
   идентичны 0.24↔0.25: 8×200 / 1×400 / 1×401 / 22×403 / 3×404 /
   4×405 / 3×500; 403 — /cron/* и /schedules/* без боевых секретов
   стенда, 500 — известные артефакты стенда /repos* respond_html, 404 —
   пустая БД). 0.25-инстанс дополнительно прошёл guard-пробу (rc=2) и
   бут на боевом sqlite (дубли-колонки миграций — штатно, try-пойманы).

## Что намеренно НЕ включено

- Новые возможности 0.25 (эффект-модель билтинов, statement-kind
  taint-инференс как аудиторская поверхность) — потребность не заявлена;
  audit-профиль офиса не изменился (42=42, 0 Category A).
- Выведение mlog-020 из ротации (ADR-0007 оставлял условным): VM/
  interpreter-гарантии в проде ещё не прошли soak; фолбэк сохраняется
  до гейта ADR-0141.
- Миграция долга №327 и снятие моста №421 — долг сохраняется (42=42).
- scripts/tryrun_all.sh и scripts/smoke_349.sh — исторические
  одноразовые скрипты №349, ссылки в них устарели намеренно.
