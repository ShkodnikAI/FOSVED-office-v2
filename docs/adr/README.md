# Индекс решений (ADR) — FOSVED-office-v2

Формат и практика — адаптированы из `docs/adr/` проекта Metalogos.
Каждое решение — отдельный файл `NNNN-краткое-название.md`. Не
пересматривать без явного запроса владельца (см. `AGENTS.md`, §3, §6).

| № | Тема | Статус |
|---|---|---|
| 0001 | Разные цвета отделов (DEPT_COLORS) — не сводить к одному акценту | принято |
| 0002 | Тёмно-красная тема FOSVED — основной язык интерфейса, «Диспетчерская» — предыдущая эпоха | принято |

Заводить новую запись при каждом решении такого класса: меняет
идентичность продукта, необратимо, или уже один раз обсуждалось и
могло бы быть переоткрыто по ошибке (см. `AGENTS.md`, §1 — расхождение
кода и памяти о прошлой сессии).
