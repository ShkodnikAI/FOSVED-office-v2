# ADR-0003: Домены детерминированного API-скана ЛЗ (arXiv/HN/GitHub) — tech и economics

**Статус:** принято (наряд #221, блок A.2 — «явное решение, не молчаливый выбор»)
**Дата:** 2026-09-19
**Контекст решения:** наряд #221, инцидент владельца с выдуманным отчётом ЛЗ (PR #219)

## Контекст

Общий путь `/lz <произвольный текст>` (dept/lz.mlog::HandleLZ → BuildLZContext)
долго собирал контекст только из статичного ярлыка сфер (LZWorldKB), вотчлиста
и планового скана LZ Daily — детерминированные API-источники
(`proxy/lz_sources.py`: arXiv, HN Algolia, GitHub Search, собранные в
`lz_api_scan`) из этого пути не вызывались вообще. PR #219 добавил живой
Tavily-поиск всем пяти доменам, но Tavily — широкий веб, а не предметные
базы; наряд #221 потребовал подключить детерминированные источники и ЯВНО
решить, по каким доменам они запускаются.

## Решение

Детерминированный скан (`lz_api_scan` через call_python-мост) запускается для
**двух** доменов из пяти:

- **tech** — все три источника в полном объёме: arXiv (препринты),
  HN (дискуссии/запуски), GitHub (активные репо по теме).
- **economics** — те же три источника осмысленно покрывают классы данных:
  arXiv содержит q-fin/econ (квантитативные финансы, эконометрика),
  HN — VC/финтех/стартап-дискуссии, GitHub — финтех- и аналитические репо.

**politics, geopolitics, events — скан НЕ запускается.** Обоснование:
arXiv/HN/GitHub — технические базы, они не являются источниками
политической/событийной разведки; их выдача по таким темам была бы шумом,
выдача «для вида» — та же выдуманность, которую чинит наряд. Эти домены
уже получают широкий веб через LZTavilySearch (PR #219).

Два класса данных работают **параллельно, не заменяя друг друга**: в общем
пути /lz Tavily-блок и APIscan-блок контекста сосуществуют.

## Последствия

- Тема для скана извлекается коротким LLM-вызовом (2–4 английских
  ключевых слова; fallback — усечённый запрос). Пустая выдача источников —
  честная строка «не нашёл релевантных результатов» в контексте (A.3), не
  молчание.
- Расширение на другие домены — только через правку этого ADR и условия в
  `dept/lz.mlog::LZApiScanContext`, не молчаливым добавлением.
