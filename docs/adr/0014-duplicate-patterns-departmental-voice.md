# ADR-0014: Дубли паттернов mlog — голос отдела важнее дедупликации (наряд #449 A.2)

**Статус:** принято (исполнительская часть наряда #449 [P2][CLEAN], волна «аудит 2026-09-30»; решения владельца 2026-10-02: STRING_ONLY не трогать, дубли — одна реализация в `utils.mlog` **или** явное ADR).
**Дата:** 2026-10-02
**Проверка:** сверка реализаций — `scripts/compare_dupes.py` (вывод в отчёте PR); реестр — `scripts/dead_pattern_registry.py`.

## Контекст

Аудит 2026-09-30 нашёл 8 паттернов, определённых в 2–3 отделах одновременно:

| Паттерн | Отделы | Реализации |
|---|---|---|
| `ApplyDisclaimer` | legal, qa | **разные**: legal — безусловная склейка; qa — гвард «не вставлять дважды» + свой `QA_DISCLAIMER_BOTTOM` |
| `DISCLAIMER_TOP` / `DISCLAIMER_BOTTOM` | design, engineering, legal | **разные**: текст дисклеймера — голос отдела (дизайн: «Дизайн-спецификация…»; инженерия: «ПРЕДВАРИТЕЛЬНО. Проверка дипломированным инженером…» — дисклеймер безопасности; legal — юридическая формулировка) |
| `EnforceHardRules` | legal, qa | **разные** |
| `QuarterlyMethodologyReview` / `RunQuarterlyMethodologyReview` | engineering/qa, design/legal | **разные** |
| `SearchArchive` | engineering, legal, utils | **разные** |
| `WrapWithDisclaimer` | design, engineering | тела идентичны, **но** замыкают `DISCLAIMER_TOP/BOTTOM` своего отдела: дедуп одной «общей» версией сломал бы резолюцию дисклеймеров (неймспейс-неопределённость при множественных определениях) |

## Решение

**Не дедуплицировать.** Вариант «одна реализация в `utils.mlog`» применим только к байт-идентичным реализациям без внешних зависимостей — среди этих 8 таких нет (единственный кандидат `WrapWithDisclaimer` отброшен из-за замыкания на отделные `DISCLAIMER_*`).

Обоснование по §2 AGENTS.md: отдел — самостоятельный специалист со своим голосом. Дисклеймер инженерии несёт требование безопасности («дипломированный инженер»), QA — техническую гварду повторной вставки, дизайн — проектную оговорку. Унификация стёрла бы эти различия — это не копипаст-долг, а осознанная кастомизация.

## Следствия

1. Дубли остаются в отделах; этот ADR — их охранная грамота (гвард `tests/test_n449_dedupe.py` проверяет, что различия зафиксированы и не растут: список дублей == 8, сверка статуса реестром).
2. При появлении НОВОГО дублирующегося паттерна с идентичной реализацией и без замыканий на отделные сущности — дедуп в `utils.mlog` обязателен.
3. Реестр (`scripts/dead_pattern_registry.py`) продолжает маркировать дубли; рост списка сверх 8 — сигнал в CI (warning).

## Дополнение 2026-10-04 (переход Metalogos 0.28.0, ADR-0015)

Семантический гейт №523 (0.28.0) блокирует `mlog serve` при дубликатах с
РАЗНОЙ арностью: глобальная таблица паттернов резолвит имя к первому
определению (проба 0.27.1: `probe_resolve` — вызывает локальный вариант
даже изнутри файла-определителя к первому глобальному), и вызов чужой
арности становится отказом бута. Охранная грамота не отменяется — она
не распространяется на дубли, которые физически не могут сосуществовать
под одним именем:

- `EnforceHardRules` (legal 3-арг / qa 4-арг): QA-вариант переименован в
  `QaEnforceHardRules` — голос QA сохранён. `EnforceHardRules` покидает
  список дублей.
- `SearchArchive` (utils 1-арг / legal 1-арг / engineering 2-арг):
  engineering-вариант переименован в `EngineeringSearchArchive`. Дублем
  остаётся пара legal+utils (одинаковая арность — гейту не противоречит).

Список дублей: 8 → 7 (`scripts/compare_dupes.py`, гвард
`tests/test_n449_dedupe.py` обновлены согласованно).

## Дополнение 2026-10-16 (наряд #514: недетерминированный бут — разводка всех дублей)

Бут-логи прода 13.10 показали: порядок резолва дублей НЕДЕТЕРМИНИРОВАН
(07:41:30 «already in utils, redefined in legal», 07:41:33 — наоборот).
Поведение офиса различалось между рестартами без изменений кода; скрытый
риск: `app.mlog /search` парсит JSON именно utils-версии `SearchArchive`
— при выигравшей legal-версии `/search` падал бы на parse_json.

Решение — разводка всех оставшихся дублей (7 → 0) переименованием с
dept-контекстом; голос отдела сохранён ПОЛНОСТЬЮ — тела не менялись:

- `SearchArchive` — авторское место `dept/utils`; legal-вариант →
  `LegalSearchArchive` (engineering-вариант ушёл в 2026-10-04);
- `DISCLAIMER_TOP/BOTTOM` → `LegalDisclaimerTop/Bottom`,
  `EngineeringDisclaimerTop/Bottom`, `DesignDisclaimerTop/Bottom`;
- `RunQuarterlyMethodologyReview` → `LegalQuarterlyMethodologyReview` /
  `DesignQuarterlyMethodologyReview`;
- `QuarterlyMethodologyReview` → `EngineeringQuarterlyMethodologyReview` /
  `QaQuarterlyMethodologyReview`;
- `WrapWithDisclaimer` → `EngineeringWrapWithDisclaimer` /
  `DesignWrapWithDisclaimer`;
- `ApplyDisclaimer` → `LegalApplyDisclaimer` / `QaApplyDisclaimer`.

Вызовы слотов `dept/scheduler.mlog` перевязаны на dept-имена. Гварды:
`tests/test_n514_unique_patterns.py` (уникальность всех имён по dept/*,
совместимость вызова app.mlog /search с utils-сигнатурой); гвард
`tests/test_n449_dedupe.py` обновлён: список дублей 7 → 0.

Охранная грамота текстов (§2 AGENTS.md: голос отдела) продолжает
действовать: отделные дисклеймеры/обзоры не унифицированы — разведены
только ИМЕНА, резолв стал детерминированным.
