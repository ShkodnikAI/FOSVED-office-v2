# ADR-0011: политика скрейпинга SHOP — снятие robots-красной линии #172

Дата: 2026-09-27. Наряд: office#406 (волна «отчёт 2026-09-27», диспатч #403).
Статус: принято. Решение владельца: комментарий в #172 (2026-09-27) —
«снять красную линию #172 (robots.txt / антибот)».

## Контекст

Правило «robots.txt уважается всегда» (#172, SHOP-2) реализовывалось
статическими отказами в сборщиках: 21vek и Tomas.by (#328/#338) закрыли
ВСЮ поисковую поверхность для честных клиентов (Disallow *?*), то есть
платформы своими robots.txt заблокировали не только ботов, но и обычные
браузерные сценарии. Владелец решил снять красную линию и подключить
закрытые только правилом площадки.

## Решение

1. **Снято**: robots.txt больше не является основанием отказа в сборщиках
   и в транспорте web-MCP (`mcp_servers/web`: проверка robots по умолчанию
   ВЫКЛЮЧЕНА; вернуть старое поведение — env `SHOP_ROBOTS_RESPECT=1`).
2. **Сохранено** (не меняется этим ADR):
   - rate-limit и кэш транспорта SHOP-2 (вежливость к площадкам остаётся);
   - SSRF-гейт web-MCP и числовые контракты URL (#408);
   - честный отказ вместо падения/пустоты: площадка, которая не отдаёт
     данные (антибот, GeoIP, смена формы), отвечает kind с диагнозом;
   - ALLOWLIST источников и kill-switch SHOP_ENABLED.
3. **Живые сборщики** вместо статических отказников: `collect_21vek` и
   `collect_tomas` пробуют реальную форму при каждом сборе — если egress
   прода или поведение площадки отличаются от песочницы, витрина
   подхватывается без правки кода; иначе честный отказ с диагнозом
   (21vek: SPA, витрина session-bound — recon_unreachable; Tomas.by:
   антибот-стена recaptcha — antibot_blocked). UniShop — антибот reagate,
   ждёт браузерный контур (решение владельца); Ozon headless — флаг не
   включаем (Chromium ~300 МБ при 512 МБ сервера); 7745/Shop.by — GeoIP
   403, нужен белорусский egress (решение владельца).

## Последствия

- Юридическая/этическая сторона: решение владельца задокументировано
  (#172); вежливый режим (rate-limit, кэш, честный UA) сохранён.
- Мутационная защита: тесты web-MCP для robots-отказов переведены на
  opt-in режим (SHOP_ROBOTS_RESPECT=1) — правило проверяется, но не активно
  по умолчанию.
- Апгрейд-путь: диагноз каждой площадки на проде — через
  `GET /shop/diagnose` (#407).
