# ADR-0001: Разные цвета отделов (DEPT_COLORS) — не сводить к одному акценту

**Статус:** принято
**Дата:** сессия редизайна Mini App, сентябрь 2026

## Контекст

При работе над новым тёмно-красным дизайном (см. ADR-0002) агент
ошибочно свёл `DEPT_COLORS` (14 отделов, каждый со своим градиентом)
к одному общему акценту — по аналогии с тем, что сама SPA-навигация
(`miniapp/index.html`) не красит вкладки по отделам, только текстом.

Вывод оказался неверным: владелец прислал исходный наряд
`NARAD_RICH_POSTPROCESSOR`, создавший всю систему обогащения отчётов
(`auto_enricher.py`) — он прямо предполагает свой цвет каждому отделу
как часть первоначального замысла, не случайность.

## Решение

Разные UI-поверхности живут по разным правилам:
- Навигация SPA (нижняя панель, боковая панель в альбомной ориентации) —
  нейтральная, различается только текстом/иконкой, не цветом.
- Заголовок отчёта конкретного отдела — цветная печать, своя для
  каждого из 14 отделов, по палитре, согласованной с общим языком
  (не старые ядовитые индиго/розовый/фиолетовый дореформенной эпохи).

## Следствия

- `proxy/core.py::DEPT_COLORS` — 14 разных записей `{start, end, accent}`,
  не редуцировать к одному значению.
- Резервные значения по умолчанию (там, где отдел не найден в словаре)
  — используют акцент Яны (штамп-алый), не отдельный нейтральный цвет.
- При любой новой поверхности, показывающей идентичность отдела
  (карточки в Чате, овальные кнопки, аватары) — использовать эту же
  палитру, не изобретать новую.

## Не пересматривать без объяснения

Если в будущем наряде это решение снова выглядит как «пережиток» —
сначала проверить историю коммитов/issues по ключевым словам
`DEPT_COLORS`, `разные цвета отделов`, прежде чем менять.
