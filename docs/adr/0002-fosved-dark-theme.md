# ADR-0002: Тёмно-красная тема FOSVED — основной язык интерфейса

**Статус:** принято
**Дата:** сессия редизайна Mini App, сентябрь 2026

## Контекст

Первоначальный визуальный язык Mini App («Диспетчерская» — тёплая
бумага, ink-текст, штамп-алый акцент, шрифты Newsreader/IBM Plex) был
согласован и последовательно проведён через отчёты, заголовки,
инфографику (см. историю FO-045 и последующих правок).

Владелец прислал новый логотип FOSVED (`miniapp/assets/fosved-logo-2026.jpg`)
— стилизованная двойная F, красно-белый глянцевый градиент на чёрном
фоне — и явно запросил редизайн всего интерфейса под этот логотип «с
нуля, экран за экраном, с согласованием каждого».

## Решение

Новый основной визуальный язык:
- Тёмный/чёрный фон (`--bg:#0A0A0C`), не тёплая бумага.
- Красно-белый градиентный акцент (`--red:#E8262E` → `--red-light`) —
  используется **экономно**: для главных чисел, ключевых кнопок, не
  заливкой целых экранов.
- Шрифт Poppins (геометрический, округлый) вместо Newsreader (с
  засечками) — по прямому запросу владельца («угловатый» отзыв о
  первой попытке на Manrope).
- Обе темы (тёмная/светлая) — через CSS-переменные на `:root` и
  атрибут `data-theme`, переключатель в шапке, состояние сохраняется
  в `localStorage`.

«Диспетчерская» — предыдущая эпоха дизайна, не текущий стандарт.
Старый `report_css.txt` переводится на новые токены отдельным нарядом
(issue FORGE-UI-6), не сосуществует параллельно бесконечно.

## Следствия

- Все новые экраны (issues FORGE-UI-0…13) — на этой основе.
- `DEPT_COLORS` (ADR-0001) адаптирована под новую палитру, сам принцип
  разных цветов по отделам — не изменился.
- Логотип используется двояко: компактная иконка в шапке (кроп на
  саму букву F) и полноразмерный герой-баннер на Главной с затемнением
  снизу для читаемости текста.

## Не пересматривать без объяснения

Возврат к светлой бумажной палитре как основной — требует явного
нового решения владельца, не молчаливого отката при следующем
редизайне.
