Наряд: [REA-1, issue #694](https://github.com/ShkodnikAI/FOSVED-office-v2/issues/694).
Дата внедрения: 2026-11-10. Инструмент: **rea-agents** («Reverse Engineer Anything», MIT).

Факты ниже помечены источником: **«по README»** — из официального README/справки
инструмента; **«прогон»** — из реального запуска в песочнице офиса (вывод команды
рядом). Ничего непомеченного не является фактом об инструменте.

## 1. Официальные источники (ставить только отсюда)

- GitHub: `github.com/morluto/rea` · сайт: `rea.tools` · npm: `rea-agents` (по README).
- README предупреждает о клонах-подделках — пакеты с похожими именами из
  неофициальных источников не ставить (по README).
- Версия в офисе запинена в обёртке: `rea-agents@6.8.0`. Авто-обновление
  запрещено: апгрейд — осознанным коммитом (`rea update`), иначе Evidence
  разных прогонов несравнимы.

## 2. Когда разбор обязателен

Новый сторонний артефакт не принимается в проект (не попадает в `package.json`
рабочей зависимости, не вшивается в образ, не кладётся в `bin/`/`mcp_servers/`)
без статического разбора, если это:

1. **npm-пакет** (JS) — добавление или мажорное обновление зависимости;
2. **Electron-приложение** (в т.ч. ASAR) — любой кандидат встраивания;
3. **нативный артефакт** — ELF/PE-бинарь, APK; включая вендоренные бинари;
4. прочий распространяемый артефакт с исполняемым кодом (wasm-бандлы и т.п.).

Минорные/патч-обновления уже принятых пакетов — разбор по решению принимающего
отдела; мажорные — всегда.

## 3. Обёртка и команды

Обёртка: `scripts/rea_inspect.sh` — пин версии, гейт node (требование по README:
22.23.4+ / 24.22.1+ / 26.12.1+), Evidence-JSON кладёт в `/tmp` с именем артефакта
и датой. Требование node и формат `--format json` — проверены прогоном (см. §6).

```bash
# JS/Electron-приложение (ASAR или распакованный каталог):
scripts/rea_inspect.sh analyze-javascript-application <путь> \
  --detail summary --evidence_output /tmp/<имя>.bundle
# крупные приложения: --detail summary + evidence_output — полный Evidence
# уходит в бандл (пилот @prisma/client: бандл 106 МБ), в stdout — сводка

# нативные артефакты (по README):
scripts/rea_inspect.sh inspect-elf-notes <elf-путь>        # notes/ABI/билд-цепочка
scripts/rea_inspect.sh inspect-pe-certificates <pe-путь>   # Authenticode-сертификаты
scripts/rea_inspect.sh inspect-pe-imports <pe-путь>        # таблица импортов PE
```

## 4. Критерии решения

Вердикт по Evidence, не по репутации. Минимальный набор проверок:

| Критерий | Где смотреть | Красные флаги |
|---|---|---|
| Сетевые эндпоинты | request-family, javascript-routes (по README) | эндоинты вне домена поставщика/назначения пакета; обфусцированные URL; WebSocket в неожиданные места |
| Обфускация | parse-статистика прогона | parse failures ≠ 0; имена модулей нечитаемы при неминифицированном upstream; eval/new Function из строк |
| Native add-ons | `.node`-файлы, `native_addon_bindings` | нативный код без исходников; add-on не заявлен в README пакета |
| IPC-поверхность Electron | ipc-секция Evidence | dynamic_channel_operations без пары; renderer→main без sender-валидации |
| Целостность | `integrity-policy` (по README: fail по умолчанию) | расхождение заявленной целостности |

Вердикты: **принимаем** (флагов нет, поверхность соответствует назначению) /
**условно** (принимаем с перечнем условий: изоляция, пин версии, запрет сетевых
эндпоинтов в прод-окружении) / **отклоняем** (красные флаги не объяснены).

## 5. Границы легальности и безопасности

- Разбираем **только свои или авторизованные** артефакты (DISCLAIMER.md
  morluto/rea — по README).
- Не подаём в анализ артефакты с чувствительными данными клиентов — результаты
  работы инструментов получает модель (наряд #694).
- Артефакт не выполняется: разбор статический, код не запускается (по README:
  «bundle bootstrap code was never executed» — подтверждено и прогоном).
