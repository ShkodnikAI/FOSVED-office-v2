## 3. Новые находки 25.09

### 3.1. `/osp/analyze` — всегда 403: двойной redact убивает авторизацию (баг)

`app.mlog:1688-1691`:

```
let received = redact(query_param("secret"), "all")     // ← маскирует значение
...
if redact(received, "hash_only") != redact(expected, "hash_only") then { return respond("403 Forbidden") }
```

`redact(·, "all")` по контракту заменяет секрет (имя `secret` матчится паттерном `*SECRET*`) на `[REDACTED]` **до** хэширования — хэш маски равен хэшу маски и никогда не равен хэшу настоящего `CRON_SECRET`. Эмпирическое подтверждение: проба с верным секретом в песочнице → `403 Forbidden` и на 0.24, и на 0.25 (паритет). Контраст: `/schedules/bootstrap` (app.mlog:1815-1816) сравнивает хэши **без** предварительного «all» — и работает (200 KEEP×7 в бут-логах). Следствие: **мост LZ→ОСП (№318) мёртв на слое авторизации**, несмотря на починенный порт; правило ЛЗ «эмиссия → ОСП» не срабатывает ни разу. Фикс — одна строка: убрать первый `redact(·, "all")` и хэшировать сырой `query_param("secret")` (утечки нет: наружу идёт только хэш, логи уже через redact).

### 3.2. `/api/expert/*` — мёртвый класс роутов (незакрытый хвост наряда)

`reverse_proxy.py:137` форвардит `/api/expert/` на mlog с комментарием «served by mlog (dept/expert.mlog)», но в модуле REST-обёртки **удалены**: `dept/expert.mlog:804` — «TODO: REST-обёртки удалены (несуществующий синтаксис serve), … Восстановить через mlogserver route — отдельным нарядом». Остались только комментарии-спецификации (:805-811). Аналогично `/api/lz/` (:138): у `dept/lz.mlog` mlog-роутов нет вовсе — LZ API живёт на Python-слое (`proxy/lz_github.py`: `/lz/diagnose`, `/lz/api-scan`, `/lz/github-scan`, `/news/*`). Комментарии форвардера ложны в обоих случаях.

### 3.3. VERSION — артефакт рантайма в git

`VERSION` пишется entrypoint'ом из `RENDER_GIT_COMMIT` при каждом буте; в git закоммичен снимок с SHA `6dcebbe`, которого в локальной истории нет (авто-коммит 8477824) — деплой-коммит прода неподтверждён (подробно в `docs/render-dashboard.md`). Рекомендация: `.gitignore` для `VERSION` + убрать из индекса.
