# current-prompts/ — нынешние боевые профили отделов

Копия `library/*.md` из репозитория на момент 2026-09-24. Это то, что
`ReadDeptProfile(dept)` реально читает и отдаёт модели прямо сейчас —
для сравнения с `../dept-originals/` (исходные наряды/планы,
часть под старую платформу).

## Известная находка — не тратить время повторно

`upravlenie.md` — мёртвый дубль `yana.md` (почти идентичный текст).
Проверено: `ReadDeptProfile` читает файл по имени `dept`, а Яна
работает под `dept="yana"` — `upravlenie.md` реально никогда не
загружается кодом. Не отдельный отдел, забытый хвост (тот же класс
находки, что `dept/app.mlog` — см. issue #283).

## Соответствие dept/*.mlog

Каждому `<dept>.md` здесь соответствует код `dept/<dept>.mlog` в
корне репозитория (кроме `upravlenie.md` — см. выше). Сверка
профиль-против-кода для Finance уже сделана (`docs/departments/
finance.md`) — тот же метод применим к остальным.
