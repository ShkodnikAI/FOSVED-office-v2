# uploads/ — папка приёма материалов от владельца

Служебная папка для закачки исходных материалов (промпты отделов, архивы, документы).

- Содержимое — исходники для анализа, НЕ часть рантайма офиса (код/деплой не читают эту папку).
- Можно закидывать: `.md`, `.txt`, `.zip` (до 25 МБ на файл через веб-интерфейс GitHub).
- Использование: Add file → Upload files прямо в эту папку, затем коммит.

Задача-потребитель: анализ промптов по отделам (написаны под другую платформу)
против нативной реализации Metalogos — «запланировано vs реализовано», все пути
запросов и ответов, итог в табличной форме (.md-отчёт).
