## Блок C — вкладка «Скилы»

- **Схема новой сущности спроектирована до фронтенда** (как требовал наряд) — `forge_project_skills`:
  ```sql
  CREATE TABLE IF NOT EXISTS forge_project_skills (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    project_slug TEXT NOT NULL,
    type TEXT DEFAULT 'text',          -- file | link | text
    title TEXT,
    content_ref TEXT,                  -- ссылка / текст / путь файла
    created_at TEXT DEFAULT (datetime('now')))
  CREATE INDEX IF NOT EXISTS idx_forge_skills_project ON forge_project_skills(project_slug, id)
  ```
  Создание — ленивое `CREATE IF NOT EXISTS` в эндпоинтах (тот же паттерн, что forge/narad-контур), отдельной миграционной системы в проекте нет.
- **Переключение вкладок** — display-toggle без перезагрузки (паттерн `showTab` из наряда), шапка (статус/название/заказчик/дата) общая, контейнеры `#tabProject`/`#tabSkills` единственные (гварды).
- **Список скилов**: иконка по типу — 📝 текст, 🔗 ссылка (отдельный тип с другой иконкой), 📄 файл; title + content_ref. **Обязательная надпись дословно**: «Только для этого проектах. Не попадают в общую библиотеку офиса и не видны другим проектам.»
- **Добавление**: text/link — реально (POST → INSERT → audit `forge_project_skill_added`); **загрузка файлов — честный пробел**: механизма загрузки файлов в проект на бэкенде нет, кнопка «Загрузить файл (в разработке)» даёт тост, эндпоинт отклоняет type=file (400) — не мимикрия (Smoke-6, по наряду).

- Конфликт тестовых схем: `test_fo042` кладёт в общую тестовую БД усечённую `forge_projects` (без goal/description) — `CREATE IF NOT EXISTS` её не обновлял. Фикстура UI-7 теперь дропает и пересоздаёт полную схему (зафиксировано в коде).
