### Маршрутизация (SPA)

```javascript
// Hash-based routing
window.addEventListener('hashchange', () => {
  const route = location.hash.slice(1);
  renderScreen(route);
});

// Маршруты
// #/              → Главная
// #/dept/osp      → Отдел
// #/chat          → Чат (Яна)
// #/chat/osp      → Чат (ОСП)
// #/report/id     → Отчёт
// #/models        → Модели
// #/economics     → Экономика
// #/settings      → Настройки
// #/narads        → Наряды
// #/archive       → Архив
```

### API endpoints (Mini App → сервер)

```
GET  /api/dashboard         → KPI + alerts + dept cards
GET  /api/dept/:slug        → dept details + tasks + skills
GET  /api/chat/:dept        → chat history
POST /api/chat/:dept        → send message
GET  /api/models            → model statuses
GET  /api/economics         → cost data
GET  /api/narads            → narad list
POST /api/narads/:id/approve → approve
GET  /api/archive           → search results
GET  /api/report/:id        → report HTML
GET  /api/admin/status      → admin stats
```
