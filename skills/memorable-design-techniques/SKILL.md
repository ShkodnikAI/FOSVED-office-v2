# Memorable Design Techniques — Make Insights Stick

A pretty visual gets a "nice" reaction. A memorable visual gets recalled a week later in a meeting. The difference is design-craft, not artistic skill. This skill catalogs the techniques that produce memorability — measured via Visual Recall Test, not aesthetic preference.

## Prerequisites

- `visual-grammar` loaded (brand colors, typography)
- `compression-principle` loaded (1-3-7 hierarchy)
- Source identified with clear central insight

## Core principle

> Memory is encoded through emotion, contrast, and meaning — not information density. A single striking image of "Tritium supply is 30 kg globally vs 50 kg/year needed for one fusion plant" stays in memory longer than a bar chart of 12 fusion startups. Apply techniques that work WITH brain's encoding biases, not against them.

## Cognitive foundations

### System 1 design (Kahneman)

Brain processes visuals in two systems:
- **System 1:** fast, automatic, pattern-matching, emotional (first 1-3 seconds)
- **System 2:** slow, deliberate, analytical (after System 1 forms impression)

For memorability, target System 1: what does the brain grasp in 2 seconds without focused attention?

That should be the **central insight**. Everything else is for System 2 reading later.

### Anchoring effect

A number alone is forgettable. "30 kg" — meaningless. "30 kg vs 50,000 kg/year needed" — anchored, comparable, memorable.

Always anchor key numbers against a reference (benchmark, baseline, opposite, expected).

### Picture superiority effect

Images recalled better than text 65% vs 10% after 3 days (Paivio research). Convert text claims into visual encodings wherever possible:
- "Compact tokamak vs traditional" → side-by-side scale visual
- "Reaction temperature 100M K" → comparison icon (sun, lightning, lava)
- "Brier score 0.18" → gauge showing position on 0-1 scale

## Composition techniques

### Golden ratio (1.618:1)

For key compositional decisions, use 1.618:1 proportions:
- Header height : content height
- Hero element width : supporting elements width
- Color contrast areas

Why: brain detects golden ratio subconsciously as "balanced". Off-ratio looks awkward without viewer knowing why.

Practical: on 1080×1350 canvas, split as ~520 / 830 (hero / body), not 50/50.

### F-pattern reading flow

Eye scans Western-language visuals in F-pattern:
1. Horizontal sweep at top (wide attention band)
2. Slightly shorter sweep below (some elements catch eye)
3. Vertical scan down left edge (looking for section markers)
4. Decreasing horizontal sweeps as eye descends

**Implication:** put dominant insight at top of canvas (horizontal sweep zone), supporting structure starting from left edge, details below.

**Anti-pattern:** important info bottom-right (eye rarely lands there without prompt).

### Z-pattern (alternative)

For visuals with strong dominant element and 2-3 supporting elements:
- Top-left: starting point (eye lands)
- Top-right: anchor (eye moves horizontally)
- Diagonal sweep down to bottom-left
- Bottom-right: conclusion (call to action / takeaway)

Use Z when narrative has clear sequence. Use F when scanning for structure.

### Rule of thirds

Divide canvas into 3×3 grid. Place key elements at intersections, not center.

Center placement = static, formal. Off-center placement = dynamic, attention-grabbing.

## Color psychology (within brand palette)

Brand palette is fixed. But WHERE colors are placed determines emotional reading:

- **Gold (#c9a961)** placed prominently = importance, value, attention
- **Burgundy (#8b2942)** placed prominently = warning, risk, urgency
- **Forest (#2d5f3f)** placed prominently = growth, safety, validation
- **Navy (#1a1a2e)** as background = depth, seriousness, professionalism
- **Cream (#f5f1e8)** as background = approachability, warmth

Apply intentionally:
- Memorable visual about RISK → burgundy dominant
- Memorable visual about OPPORTUNITY → gold + forest
- Memorable visual about SYSTEMIC ANALYSIS → navy + cream + gold accents

## Emotional hooks

### Scale comparison

Convert abstract magnitudes into relatable scales:
- "10^18 J of energy" → "= 50 hydrogen bombs"
- "30 kg tritium" → "= 30 bags of sugar globally"
- "$3B reactor" → "= 0.4% of US defense budget annually"

Visualize the comparison side-by-side. Brain anchors on the relatable scale.

### Faces and human elements

A face increases attention 100-300% (eye-tracking studies). For visuals where it fits:
- Key person photo (small, top corner) if discussing their project
- Stylized human silhouettes for "this many people"
- Pointing/gesture lines to direct attention

In brand context: rarely use photos (brand is data-focused). But human silhouettes for scale comparisons work.

### Surprise / counter-intuitive

If insight is counter-intuitive, lean into it:
- "Most fusion startups will fail. Including the one I'm meeting tomorrow." (high contrast, declarative)
- Visual: 10 fusion startup logos, 9 grey, 1 highlighted — flip viewer's assumption

Surprise encodes faster because brain notes anomaly.

### Motion implied

Static SVG can imply motion through:
- Arrows showing direction
- Trail lines fading from past to future
- Wedge/cone shapes suggesting flow
- Size gradients (small to large) showing growth

Used sparingly. Implied motion ≠ animation; don't actually animate (overdone).

## Gestalt principles

Apply for grouping and structure:

### Proximity
Elements close together = related. Wide gap between groups separates them.
Implication: control spacing precisely. Don't leave related elements far apart.

### Similarity
Same visual treatment = same category. Different = different category.
Don't visually differentiate items that are conceptually same — confuses viewer.

### Closure
Brain completes broken shapes. A C-shape is read as circle. A dashed line is read as line.
Use to imply structure without drawing it all (saves data-ink).

### Continuity
Eye follows curves and lines. Use leading lines to direct attention from one element to next.

### Figure/ground
Strong figure on quiet ground stands out. Busy ground obscures figure.
Maximize negative space around dominant element.

## Visual metaphors

Map abstract concepts to concrete visuals:

- **Time progression** → timeline, hourglass, sun arc
- **Hierarchy** → pyramid, tree, layers
- **Cycle** → circle, loop, recurring arrows
- **Comparison** → balance scale, side-by-side scale
- **Risk** → cliff edge, tightrope, scales tipping
- **Opportunity** → open door, dawn, ascent
- **System** → gears, network, ecosystem
- **Disruption** → lightning, fracture, wave

Metaphors must be brand-appropriate (no cartoonish, no clichéd). Use stylized line-icon style consistent with brand grammar.

## Information density tuning

For memorability, LESS is more:

- Type 1 Compression: high density (10-20 elements) — purpose is comprehensive
- Type 2 Memorable: low density (3-7 elements max) — purpose is sticking

If a memorable visual has 15 elements, it's not memorable — it's a compression visual with worse layout.

## Worked example

**Source:** Expert briefing on fusion startup investment. Central insight: "Compact tokamaks face universal tritium supply crisis, this startup has no plan."

**Type 2 Memorable Infographic design:**

**Composition:** Z-pattern. Golden ratio split.

**Top-left:** large stylized image of compact tokamak (representative, not specific startup) in line-icon style — navy outlines on cream background.

**Top-right:** very large gold number "30 kg" with caption "global tritium supply".

**Diagonal sweep:** subtle line from "30 kg" down to bottom-left.

**Bottom-left:** very large burgundy number "50 kg/year" with caption "needed per first commercial plant".

**Bottom-right:** small navy text "FusionCorp has no announced tritium plan." with subtle burgundy underline.

**Color application:** gold (current supply, surprising small number) → burgundy (need, alarming gap) → navy declarative statement.

**Emotional hook:** the 30 vs 50 contrast. Visual scale comparison embedded (30 small dot, 50 big dot).

**Recall test 30 days later:** viewer should remember "tritium supply 30 kg vs 50 needed, no plan". That's the insight. Names, dates, other details — fine if forgotten.

## Anti-patterns

- **Over-decoration.** Adding visual interest at expense of meaning. Every element must serve insight.
- **Forcing emotion.** Hyped headlines that source doesn't support — manipulative, owner notices, trust degrades.
- **Wrong color semantics.** Using gold for warnings or burgundy for opportunities — violates brand grammar.
- **All techniques at once.** Golden ratio + F-pattern + Z-pattern + scale comparison + faces + motion + metaphor in one visual = chaos. Pick 2-3 techniques per visual.
- **Cliché metaphors.** "Lightbulb for idea", "rocket for growth" — too generic, lose impact.
- **Generic stock-photo-style human silhouettes.** Off-brand. Use minimal line silhouettes only.
- **Animation in static archive.** Don't waste effort on motion that won't render.
- **Treating memorable as "make it pretty".** Memorability is measurable (Recall Test). Aesthetic alone is not enough.

## Recall test as quality gate

After generation, the visual must pass Visual Recall Test eventually (1-3 months later).

Pre-publishing self-test: imagine seeing this for 5 seconds, then 30 days later being asked "what did that infographic say?" Can you answer with the central insight?

If no — redesign. Less elements, stronger hierarchy, sharper emotional hook.
